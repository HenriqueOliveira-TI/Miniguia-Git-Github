# Miniguia Git e GitHub

## Sobre o projeto

Este projeto apresenta os fundamentos do Git e GitHub para desenvolvedores iniciantes.

O objetivo é reunir, de forma simples e prática, conceitos essenciais para compreender o controle de versão e o trabalho com repositórios.

## Conteúdos

- O que é Git
- O que é GitHub
- Repositório
- Commit
- Branch
- Merge
- Pull Request
- Push
- Pull
- Clone

## Fluxo básico

Alteração → Staging Area → Commit → Push → GitHub

GitHub → Pull → Computador

## Aprendizados

Durante a construção deste miniguia serão realizados exercícios práticos utilizando Git e GitHub.

O projeto também registra dificuldades, erros e aprendizados encontrados durante o processo.
